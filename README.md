## 📌 The problem

Recruitment and onboarding data usually sits in separate lists. HR has to check each one by hand to find out who is stuck, who has not joined, and whose induction is late. This project joins those lists so the status of each candidate is clear at a glance.

## 🎯 Objectives

- Track every candidate through the recruitment pipeline
- Monitor interview and selection status
- Surface pending compliance activities
- Track offer and joining status
- Monitor induction and onboarding progress
- Generate each candidate's overall status automatically

## 🚦 Automated status tracking

Each candidate gets one status, generated by formula. Rules are checked in order, and the **first match wins**.

| Priority | Status | Triggered when |
|:---:|---|---|
| 1 | 🔴 **Compliance Pending** | The compliance status is "Compliance Pending" |
| 2 | 🟠 **Offer Extended - Awaiting Joining** | The candidate is Selected and the joining field is empty |
| 3 | 🔴 **Induction Overdue** | The candidate has joined but induction is marked "N" |
| 4 | 🟡 **Awaiting Interview** | The candidate is "Not Yet Interviewed" |
| 5 | 🟢 **On Track** | None of the above apply |
| ➕ | ⚪ **Not Onboarded** | The candidate is not found in the Onboarding Progress sheet |

## ⚙️ Key Excel formulas

**1. Connecting two sheets, with error handling**
```excel
=IFERROR(VLOOKUP(A9,Onboarding_Progress!$A$2:$D$9,4,FALSE),"Not Onboarded")
```
Looks up the candidate in the Onboarding Progress sheet and returns the onboarding information. If the candidate is not found, it returns **Not Onboarded** instead of an error.

**2. Automated candidate status**
```excel
=IF(E7="Compliance Pending","Compliance Pending",
IF(AND(F7="",D7="Selected"),"Offer Extended - Awaiting Joining",
IF(AND(F7<>"",G7="N"),"Induction Overdue",
IF(D7="Not Yet Interviewed","Awaiting Interview","On Track"))))
```
A nested `IF` with `AND` tests several conditions in order and returns the first status that applies.

## ⚠️ Limitations and risks

| Limitation | Why it matters | Planned fix |
|---|---|---|
| The lookup range is fixed (`$A$2:$D$9`) | New candidates added below row 9 will not be found | Convert the data to an Excel Table or use a larger range |
| Status rules depend on exact text such as "Compliance Pending" and "N" | A spelling variation breaks the rule | Dropdown lists with data validation |
| The sample data is small | Patterns are illustrative | Test with a larger candidate list |
